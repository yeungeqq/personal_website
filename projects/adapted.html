AdaptEd

An educational assessment prototype that turns recorded naming exercises into reviewable results.

  • React
  • TypeScript
  • Express
  • AssemblyAI

The idea

AdaptEd is a hackathon prototype for teacher-led educational assessments. Its implemented Rapid Automatized Naming workflow connects a color-grid exercise, microphone recording, speech transcription, and scoring.

Project scope

  • Provide separate teacher and student dashboard experiences.
  • Record spoken responses to a fixed color-grid exercise.
  • Send recordings for transcription through AssemblyAI.
  • Calculate accuracy, errors, and naming speed for review.

Technical approach

A React and TypeScript interface handles the exercise and audio capture. An Express backend accepts recordings, coordinates transcription, and returns scoring results. The workflow makes an external speech API part of a complete user interaction rather than an isolated API call.

Scope & limitations

AdaptEd is an educational assessment prototype, not a clinically validated diagnostic tool. Handwriting recognition and behavioral questionnaires are planned extensions, not presented here as implemented features. Demo authentication is not evidence of production security.
